# Посты для Threads

Здесь хранятся черновики и история постов. Публикует их воркер Cloudflare из репозитория `oxionezhkov-hub/mybrand-smm`, файл `threads/threads.js`. Он же присылает отчёты в Telegram.

## Как устроено
1. Claude пишет посты на неделю в `queue/week-*.json`, у всех статус `pending`.
2. Посты проверяют на странице проверки (артефакт «Threads: посты на неделю»): одобрить, отклонить, поправить, прокомментировать.
3. Claude переносит одобренные посты с расписанием в `threads/queue.json` в репозитории `mybrand-smm`. После слияния воркер публикует их по времени.

Токен Threads воркер получает от workflow «Threads — передать токен воркеру» (одноразовый запуск) и дальше продлевает сам.

Статусы публикации живут в KV воркера. Посмотреть их можно по адресу `/debug/threads?token=<TG_TOKEN>`.
