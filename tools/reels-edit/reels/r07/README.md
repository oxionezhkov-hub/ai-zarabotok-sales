# r07-dental-story v1

Ролик «Сайт для стоматологии: от запроса до денег», 40 с. Части:
- M: проверенные куски IMG_3602 v2 в новом порядке (`build.py`), слова и карточки сдвинуты из r3602;
- E: удачный дубль призыва из IMG_3599.

Порядок: «Сейчас вот хорошая стратегия: зайти в карты, найти бизнес без сайта» → «и попросить сделать… сделай сайт для стоматологии» → «через минут 10–20 первый результат, первая наработка» → «бизнесу можно предложить купить сайт» → «знакомые берут 20–40 тысяч» → «час-два, не больше» → «подписывайтесь».

«Либо» в начале вырезано. Начало 98.69: «с» в «сейчас» начинается на 98.70 (видно по ZCR), а «бо» тянется до 98.69. Расшифровка при старте 98.62 слышала «бы сейчас».

Кадр куска считаем через `int()`, не `round()`: начало видео не должно быть позже AST, иначе atrim получает отрицательный start_sample и ffmpeg падает («Numerical result out of range»).
