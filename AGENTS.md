# Repository instructions

## AI Reels

For work on the mass-market «заработок на ИИ» Reels stream:

1. Read `knowledge-base/zarabotok-na-ii/AI_REELS_CONTEXT.md` for the handoff summary and unresolved decisions.
2. Before editing or rendering a video, read `.claude/skills/reels-edit/SKILL.md`; for script or interview work, also read `.claude/skills/reels-interview/SKILL.md`.
3. Read the latest `knowledge-base/zarabotok-na-ii/reels-queue.md` entry and current author feedback before deciding what to render or send.
4. Keep this Reels stream separate from CMO-brand Reels and Threads. A queue status of «approved» means author approval, not proof of publication.
5. Do not invent audience cases, prices, testimonials, earnings, or claims. Never put tokens, passwords, raw video, or private customer data into the repository.

The Reels context file is a dated handoff, not a live schedule. Verify changing facts and automation state before acting.
